# CRUD REST API

A backend RESTful API built with **Node.js**, **Express.js**, and **MongoDB**, implementing full **CRUD (Create, Read, Update, Delete)** functionality for managing resources.

## Tech Stack

- **Node.js**  - JavaScript runtime
- **Express.js** - REST API framework
- **MongoDB** - NoSQL database
- **Postman** - API development and endpoint testing

## Features

- Create new resources
- Retrieve individual and multiple resources
- Update existing resources
- Delete resources
- RESTful API endpoint architecture
- MongoDB database integration
- API testing and validation with Postman

## API Operations

|Method|Endpoint|Description|
|---|---|---|
|`POST`|`/api/products`|Create a product|
|`GET`|`/api/products`|Retrieve all products|
|`GET`|`/api/products/:id`|Retrieve a product by ID|
|`PUT`|`/api/products/:id`|Update a product|
|`DELETE`|`/api/products/:id`|Delete a product|

## Overview

This project demonstrates the implementation of a backend REST API, including HTTP request handling, database operations, route management, and API testing using Postman.
